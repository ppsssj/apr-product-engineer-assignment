# Design Retouch

이 폴더는 공식 Figma 원본이 아니라,
기존 디자인을 기반으로 의도적으로 수정한 UX 개선 레퍼런스다.

- 공식 디자인 근거: `design/design-export/` (Figma export)
- 의도적 UX 개선 근거: `design/design-retouch/` (이 폴더, `PRODUCT_DECISION`)

두 근거가 다를 때 P8-C 구현은 이 폴더를 따른다.
이 폴더가 바꾸지 않은 부분은 공식 디자인 구현을 그대로 유지한다.

## 공통 방향

- 메디큐브톡을 사람 중심 SNS보다 콘텐츠 중심 커뮤니티로 해석한다.
  사용자는 "누가 썼는지"보다 "무슨 글인지 · 요약 · 반응"을 먼저 훑는다.
- 기능/API/정보 자체는 변경하지 않는다 (새 필드 · 팔로우 · 프로필 없음).
- 기존 375px 모바일 구조를 유지한다.
- 과도한 재설계보다 정보 위계와 인터랙션 디테일을 개선한다.

## Post List

- 제목 → 본문 요약 → metadata 순으로 콘텐츠를 우선한다.
- 작성자 avatar/name은 metadata 수준으로 낮춘다.
- metadata row:
  작성자 / 댓글 수 / 좋아요 수 / 작성 시간
- 작성 시간은 오른쪽 끝에 고정한다.
- 구현: 108px row (14 + 제목 24 + 6 + 요약 18 + 13 + metadata 18 + 14 + 1px divider).
  리터치 이미지는 98px이지만 visual review에서 너무 빽빽하다고 판단해
  글자 크기는 그대로 두고 여백만 늘렸다 (375×778에서 약 7개 노출).
  긴 작성자는 132px에서 말줄임, 숫자는 `1,411`처럼 천 단위 구분.
  app bar 제목은 상세와 같은 가운데 정렬 + 하단 1px divider.

## Post Detail

- 상단 app bar에 `메디큐브톡` 제목을 표시하고, 목록과 같은 1px `#EAECEE` 하단 divider를 둔다.
- 게시글 작성자 avatar/name은 기존보다 작게 표현한다 (36px → 24px, 날짜 분리).
- 본인 글의 `⋮` 메뉴는 app bar가 아니라 작성자 row 우측에 둔다.
  수정/삭제가 "페이지 전체"가 아니라 "해당 게시글"의 action임을 명확히 하기 위함이다.
- 게시글 하단에는 좋아요(왼쪽)와 작성 날짜(오른쪽)를 metadata로 배치한다.
- 타인 글은 같은 row 높이에서 `⋮`만 없다 (본인/타인 간 세로 흔들림 없음).
  (타인 글 export의 바깥 검은 1px 테두리는 artboard 외곽선이며 디자인 요소가 아니다.)

## 코드에서 다듬은 인터랙션

- 눌림 피드백: 목록 row, FAB, 뒤로 가기, `⋮`, 좋아요 하트, 댓글 더보기,
  댓글 삭제, 등록 버튼, 바텀시트/다이얼로그 버튼.
- 진입 모션(120–180ms, opacity/transform만): 바텀시트, 다이얼로그, 토스트.
  닫힘은 즉시(언마운트 시점을 늦추지 않음). `prefers-reduced-motion`이면 모션 없음.
- 터치 영역: `⋮` 40×40, 댓글 삭제 약 37×32 (보이는 글자 위치는 그대로).
- 댓글 입력: focus 시 테두리 강조, 등록 중에는 입력 텍스트를 흐리게 표시.
- 댓글 더보기 라벨 색(#979EA9)은 공식/리터치 디자인대로 유지한다.
- 댓글 heading: `댓글`은 Bold 16/24 #292828, 개수 `(1,411)`은 보조 정보로
  Medium 14/20 #979EA9 (간격 4px). 이미지 없이 코드에서만 적용한 refinement다.
